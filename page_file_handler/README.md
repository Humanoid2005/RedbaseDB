### Learning points

- #pragma once : ensures that each header file is included only once
- #include <<cassert>> : import to use asset(<<condition>>) i.e. assert(condition is true) then program runs normally, else interrupts the program there by throwing error.
- #include <<cinttypes>> : needed to use integers types like int32_t, uint16_t, etc..
- #include <<cstdlib>> : needed to use stdlib functions like malloc, free, exit, etc..
